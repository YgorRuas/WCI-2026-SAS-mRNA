# In Silico Optimization of the Staphylococcus aureus ATP Synthase Subunit Alpha Antigen to Mitigate Glycan Shielding in mRNA Vaccines

**Presented at the 17th World Congress of Inflammation (WCI 2026) – Foz do Iguaçu, Brazil**

Welcome to the supplementary repository for our poster presentation! This space contains additional data, high-resolution files, 3D structural models, and the full references used in our *in silico* optimization pipeline.

## 🔬 Project Overview
The ATP synthase subunit alpha (SAS) is a promising vaccine target against *Staphylococcus aureus*. However, when used in mRNA vaccine platforms, the eukaryotic expression machinery can introduce bulky glycosylation modifications that physically mask B-cell epitopes ("glycan shielding"). 

In this study, we applied an *in silico* pipeline using AlphaFold 3, NetGlyc, and DiscoTope 3.0 to strategically mutate specific threonine residues (124 T-G and 126 T-G) into glycines. This targeted substitution successfully eliminates O-glycosylation attachment sites while fully preserving the native 3D folding and B-cell epitope accessibility of the SAS antigen.
